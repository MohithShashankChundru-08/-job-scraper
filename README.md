# -job-scraper
Web scraping project that extracts job data and delivers clean Excel report

## What it does
Scrapes job listings from a website, cleans the data
and generates a structured Excel report.

## Libraries Used
- Python
- BeautifulSoup
- Requests
- Pandas
- OpenPyXL

## Features
- Scrapes job title, company, location, date
- Cleans and removes duplicate data
- Detects remote jobs automatically
- Generates Excel report with 4 sheets:
  - Job Details
  - Summary
  - Remote Jobs
  - Company Analysis
